    # HurshBin Tech Platform - Demo Video Script
    ## User Flow: Admin → Head → Trainer → Learner → Session Management

    ---

    ## Introduction (10-15 seconds)

    Welcome to HurshBin Tech - a comprehensive learning management platform designed for intervention programs. Today, we'll walk through the complete user flow, from user creation to conducting live sessions.

    ---

    ## PART 1: User Management Hierarchy (2-3 minutes)

    ### Scene 1: Admin Creates Head (45 seconds)

    **[Screen: Admin Dashboard]**

    Let's start by logging in as an administrator. The admin has full control over the platform and is responsible for creating Head users who will manage their respective teams.

    **[Navigate to: Manage Heads → Register New Head]**

    We click on "Manage Heads" and then "Register New Head." 

    **[Fill out the form]**

    Here we enter the Head's basic information:
    - Name
    - Email address  
    - Contact number
    - Age and address

    **[Scroll to Professional Information]**

    Next, we add professional details:
    - Qualifications
    - Years of experience
    - Date of joining
    - Their experience with HurshBin

    **[Upload Reference Data]**

    We can also upload reference documents - these could be certificates, resumes, or any supporting documents. The system supports PDFs, images, and videos.

    **[Click Register]**

    When we submit, the system generates a unique passcode for the Head user. This passcode is displayed on screen and can be used for login.

    **[Show success message]**

    Notice the success modal showing the generated passcode. This is automatically created by the system to ensure secure access.

    ---

    ### Scene 2: Head Creates Trainer (45 seconds)

    **[Screen: Head Dashboard after login]**

    Now let's log in as the Head we just created, using the passcode that was generated.

    **[Navigate to: Manage Trainers → Register New Trainer]**

    From the Head's dashboard, we navigate to "Manage Trainers" to add a new trainer to the team.

    **[Fill trainer details]**

    Similar to the Head registration, we enter:
    - Basic information
    - Contact details
    - Professional qualifications
    - Experience details

    **[Reference Data Section]**

    Again, we can upload supporting documents for the trainer's profile.

    **[Submit Form]**

    Upon submission, a unique passcode is generated for the trainer.

    **[Show passcode in success modal]**

    The system displays the passcode which the trainer will use to access their account.

    ---

    ### Scene 3: Head Creates Learner (45 seconds)

    **[Navigate to: Manage Learners → Register New Learner]**

    Now let's add a learner to the program. We click on "Manage Learners" and select "Register New Learner."

    **[Fill learner details]**

    For learners, we capture:
    - Personal information
    - Guardian details
    - Contact information
    - Program-specific details

    **[Personal Details Section]**

    Notice we can add comprehensive information including:
    - Self-description
    - Interests
    - Future vision
    - Guardian descriptions

    **[Reference Data Upload]**

    We can upload assessment reports, medical documents, or other relevant files.

    **[Submit and show passcode]**

    Once registered, the learner receives their unique passcode for platform access.

    ---

    ## PART 2: Content & Goals Management (1.5-2 minutes)

    ### Scene 4: Admin Adds Learning Content (45 seconds)

    **[Screen: Admin Dashboard → Manage Learning Content]**

    Now let's switch back to the admin account to add learning resources to the platform.

    **[Click "Add New Content"]**

    We click the "Add New Content" button to upload learning materials.

    **[Upload File]**

    The system supports various file types:
    - Videos for visual learning
    - PDFs for documents
    - Images for reference materials
    - Audio files

    **[Fill content details]**

    We add a descriptive title and description to help users understand what this content is about.

    **[Show upload progress]**

    Notice the upload progress indicator - the system handles files up to 100MB in size.

    **[Submit and show content card]**

    Once uploaded, the content appears in a visual card format, showing:
    - Content type icon
    - File size
    - Upload date
    - Preview thumbnail

    ---

    ### Scene 5: Admin Creates Learning Goals (45 seconds)

    **[Navigate to: Manage Learning Goals]**

    Next, we set up learning goals that will guide the intervention programs.

    **[Click "Add New Goal"]**

    We click "Add New Goal" to create a new learning objective.

    **[Fill goal details]**

    Here we define:
    - Goal title
    - Detailed description
    - Associated program type (if applicable)
    - Success criteria

    **[Attach learning content]**

    We can link the learning content we just uploaded to specific goals, creating a structured learning path.

    **[Show goal in list]**

    The created goal now appears in the goals list, ready to be assigned to sessions.

    ---

    ## PART 3: Session Management & Execution (2-3 minutes)

    ### Scene 6: Head Creates Session (1 minute)

    **[Screen: Head Dashboard → Manage Sessions]**

    Back in the Head's account, let's create a learning session.

    **[Click "Create New Session"]**

    We navigate to "Manage Sessions" and click "Create New Session."

    **[Select Trainer & Learner]**

    First, we select:
    - The assigned trainer from our team
    - The learner who will participate
    - The coach who will support the session

    **[Choose Date & Time]**

    We schedule the session by selecting:
    - Preferred date
    - Start time
    - Duration

    **[Select Learning Goals]**

    Now we attach learning goals to this session. These goals will guide what the trainer and learner work on.

    **[Add Program Details]**

    We can specify:
    - Program type (IIP or Home-based)
    - Session objectives
    - Any special notes

    **[Submit Session]**

    When we create the session, all participants - trainer, learner, and coach - are notified.

    **[Show session in calendar view]**

    The session now appears in the sessions list with status "Scheduled."

    ---

    ### Scene 7: Trainer Starts Session (45 seconds)

    **[Screen: Trainer Dashboard at session time]**

    At the scheduled time, the trainer logs into their account.

    **[Navigate to: My Sessions → Today's Sessions]**

    The trainer can see their scheduled session for today.

    **[Click "Start Session"]**

    When ready, the trainer clicks the "Start Session" button.

    **[Show session interface]**

    The session interface opens with:
    - Video conferencing area
    - Learning goals sidebar
    - Interactive whiteboard
    - Session notes section
    - Learning content access

    **[Demonstrate features briefly]**

    The trainer can:
    - Share their screen
    - Use the whiteboard for interactive teaching
    - Access uploaded learning materials
    - Track progress against goals

    ---

    ### Scene 8: Learner Joins Session (30 seconds)

    **[Screen: Learner Dashboard]**

    Meanwhile, the learner logs into their account using their passcode.

    **[Show notification/session alert]**

    The learner sees a notification that their session is active.

    **[Click "Join Session"]**

    They click "Join Session" to enter the virtual classroom.

    **[Show learner's session view]**

    The learner's interface shows:
    - Video feeds of trainer and themselves
    - Shared learning materials
    - Interactive whiteboard
    - Chat or reaction features

    **[Show both screens side by side]**

    Now both trainer and learner are connected and can interact in real-time.

    ---

    ### Scene 9: Session in Progress (30 seconds)

    **[Show active session with both participants]**

    The session is now live with both participants engaged.

    **[Demonstrate real-time features]**

    Notice the real-time collaboration features:
    - Live video and audio communication
    - Shared whiteboard for visual learning
    - Access to learning content and goals
    - Progress tracking throughout the session

    **[Show session notes being taken]**

    The trainer can take notes during the session, documenting progress and observations.

    **[Show learning goals being checked off]**

    As goals are achieved, the trainer can mark them as completed, providing instant feedback.

    ---

    ## PART 4: Interactive Session Features Deep Dive (4-5 minutes)

    ### Scene 10: Trainer & Learner Login and Session Access (30 seconds)

    **[Split Screen: Trainer Dashboard | Learner Dashboard]**

    Both trainer and learner can log in using their unique passcodes generated during registration.

    **[Trainer Dashboard View]**

    The trainer sees today's scheduled sessions in their dashboard. Each session card displays:
    - Learner name and profile picture
    - Session time and duration
    - Learning goals assigned
    - "View Details" and "Start Session" buttons

    **[Learner Dashboard View]**

    The learner's dashboard shows scheduled sessions under "IIP Program" section:
    - Upcoming session notifications
    - Trainer name and photo
    - Session timing
    - "Join Session" button (becomes active when trainer starts)

    **[Trainer clicks "Start Session"]**

    When the trainer clicks "Start Session," the session page loads with all interactive tools ready.

    **[Learner clicks "Join Session"]**

    The learner receives a notification and clicks "Join Session" to enter the virtual classroom.

    ---

    ### Scene 11: Video Conferencing & Media Controls (45 seconds)

    **[Show session interface with live video feeds]**

    Both participants can now see each other through live video streams.

    **[Trainer's View]**

    The trainer sees:
    - Learner's video feed (large, prominent display)
    - Connection quality indicator (green dot = excellent connection)
    - Media control buttons

    **[Demonstrate Camera Control]**

    The trainer clicks the camera button to toggle video on/off. Notice the icon changes to show camera status.

    **[Demonstrate Microphone Control]**

    Similarly, the mic button mutes/unmutes audio. The visual feedback shows when the mic is active.

    **[Connection Quality Monitor]**

    The connection indicator shows real-time quality:
    - Green = Excellent
    - Orange = Poor connection
    - Red = Connection issues (automatic reconnection in progress)

    **[Video Feed Positioning]**

    The trainer can drag the video window to any position on the whiteboard for optimal view while teaching.

    ---

    ### Scene 12: Whiteboard & Learning Content Drag-Drop (1 minute)

    **[Focus on Whiteboard Area]**

    The main canvas area is the interactive whiteboard where all teaching happens.

    **[Show Learning Content Sidebar]**

    On the right side, the trainer sees all assigned learning content:
    - Videos with thumbnails
    - PDF documents
    - Images
    - Audio files

    **[Search for Content]**

    The trainer can search: "Type 'alphabet' in the search box..."

    **[Filter results appear]**

    All content matching "alphabet" is displayed with visual cards showing:
    - Content title
    - File type icon
    - Thumbnail preview

    **[Drag and Drop Demo]**

    Watch as the trainer drags an image from the learning content sidebar...
    - The cursor shows a ghost preview while dragging
    - Drop it onto the whiteboard
    - The image appears with smooth animation
    - The learner sees it instantly on their screen

    **[Drag a Video]**

    Now the trainer drags a learning video:
    - The video thumbnail appears on whiteboard
    - Both can see it
    - Trainer can play/pause the video
    - The learner watches synchronized playback

    **[Drag a PDF Document]**

    When a PDF is dropped:
    - It displays as a thumbnail on the whiteboard
    - Click to open full-screen PDF viewer
    - Navigate through pages
    - Zoom in/out for detailed viewing

    ---

    ### Scene 13: Bucket Organization System (45 seconds)

    **[Create a Bucket]**

    The trainer clicks the "Bucket" tool button to create an organizational container.

    **[Position and Label]**

    A bucket appears on the whiteboard. The trainer:
    - Drags it to the desired position
    - Double-clicks to edit the label: "Fruits"
    - The bucket is now labeled and ready

    **[Add Items to Bucket]**

    The trainer drags learning content items (images of apple, banana, orange) into the bucket:
    - Each item shrinks slightly to fit
    - Items stack neatly inside the bucket
    - Visual feedback shows items are contained

    **[Create Second Bucket]**

    The trainer creates another bucket labeled "Vegetables" and adds relevant items.

    **[Demonstrate Organization]**

    This helps organize learning materials by category, making it easy for learners to:
    - Group related items
    - Sort and classify objects
    - Build categorization skills

    **[Remove from Bucket]**

    The trainer can click the × button on any item to remove it from the bucket, and it returns to the whiteboard.

    ---

    ### Scene 14: Prompt & Reinforcement Meters (30 seconds)

    **[Show Prompt Meter]**

    On the left sidebar, the trainer has a "Prompt Level" meter with levels:
    - Level 0: Independent (No prompting)
    - Level 1: Gestural (pointing, nodding)
    - Level 2: Verbal (spoken hints)
    - Level 3: Physical (hand-over-hand guidance)

    **[Trainer Adjusts Prompt Level]**

    As the learner needs help, the trainer slides to Level 2 "Verbal Prompt."

    **[Visual Feedback to Learner]**

    The learner's screen shows the prompt level indicator updating in real-time.

    **[Show Reinforcement Meter]**

    Similarly, the "Reinforcement Level" meter has:
    - Level 0: None
    - Level 1: Verbal praise
    - Level 2: Tangible reward
    - Level 3: Primary reinforcer

    **[Trainer Uses Reinforcement]**

    When the learner succeeds, the trainer moves the slider to Level 1, and the learner sees positive feedback.

    **[Session Report Tracking]**

    These levels are automatically recorded in the session report for progress tracking and analysis.

    ---

    ### Scene 15: Interactive Feedback Tools (1 minute)

    **[Show Feedback Button Toolbar]**

    The trainer has a rich set of feedback buttons:

    **[Positive Feedback Buttons]**

    - **Good Job!** 👍 - Displays thumbs up animation on learner's screen
    - **Wow!** 🌟 - Shows sparkle effects
    - **Doing Well** 💪 - Displays strength icon
    - **Thank You** 🙏 - Shows gratitude gesture
    - **Loved it** ❤️ - Heart animation appears

    **[Calming Tools]**

    - **Relax** 😌 - Displays calming message for overwhelmed learners

    **[Fun Animations - Click "Bubbles"]**

    Colorful bubbles float across the learner's screen:
    - Multiple bubbles appear
    - They float upward with gentle animation
    - Learner can click to pop them (satisfying interaction)
    - Great for breaks or rewards

    **[Click "Smileys"]**

    Happy smiley faces cascade down:
    - Cheerful yellow faces
    - Bouncing animation
    - Creates positive reinforcement

    **[Click "Balloons"]**

    Colorful balloons float upward:
    - Red, blue, green balloons
    - Learner can pop them by clicking
    - Celebratory sound effects

    **[Click "Stars"]**

    Twinkling stars appear:
    - Golden stars with sparkle effect
    - Fade in and out elegantly
    - Used for achievement celebration

    **[Wait Command]**

    The trainer clicks "Wait" ⏳:
    - Learner sees a clear "Please Wait" indicator
    - Helps manage pace and expectations
    - Teaches patience and turn-taking

    ---

    ### Scene 16: Message Chat System (30 seconds)

    **[Show Chat Panel]**

    At the bottom of the session interface is a message chat area.

    **[Trainer Types Message]**

    The trainer types: "Great job on identifying colors!"

    **[Click Send]**

    The message appears in both trainer's and learner's chat windows with:
    - Sender name
    - Timestamp
    - Message text

    **[Learner Responds]**

    The learner can type back (if capable): "Thank you!"

    **[Chat History]**

    All messages are preserved for the session and included in the final session report.

    **[Use Cases]**

    - Send encouragement during tasks
    - Give written instructions
    - Communicate with guardians (if they're observing)
    - Document key moments

    ---

    ### Scene 17: Stopwatch & Task Timer (45 seconds)

    **[Show Stopwatch Panel]**

    The trainer clicks the "Stopwatch" button to reveal the timer panel.

    **[Start a Task Timer]**

    For a sorting activity, the trainer:
    - Clicks "Start" on the stopwatch
    - Time begins counting: 00:00, 00:01, 00:02...
    - The learner sees the timer on their screen

    **[Visual Display]**

    The large, clear timer shows:
    - Minutes and seconds
    - Easy-to-read font
    - Color-coded for clarity

    **[Pause Timer]**

    If the learner needs a break, the trainer clicks "Pause" - time freezes.

    **[Resume Timer]**

    Click "Resume" to continue from where it paused.

    **[Task Completion]**

    When the task is done:
    - Trainer clicks "Stop"
    - Final time is displayed: "Completed in 02:45"
    - Celebration animation may appear

    **[Set Custom Time]**

    The trainer can also set a countdown timer:
    - Click "Set Time"
    - Enter 5 minutes
    - Timer counts down: 05:00, 04:59, 04:58...
    - Alert when time is up

    **[Multiple Timers]**

    The trainer can create multiple stopwatches for different activities, tracking concurrent tasks or comparing performance.

    ---

    ### Scene 18: Whiteboard Drawing Tools (45 seconds)

    **[Show Drawing Toolbar]**

    The whiteboard has professional drawing tools:

    **[Pen Tool]**

    The trainer selects the pen:
    - Choose color (red, blue, green, black, etc.)
    - Adjust thickness (thin, medium, thick)
    - Draw freely on the whiteboard
    - Learner sees strokes in real-time

    **[Demonstrate Drawing]**

    The trainer draws:
    - A circle around an object to highlight it
    - An arrow pointing to important details
    - Writes a word or number

    **[Eraser Tool]**

    Click the eraser to remove drawn strokes:
    - Adjustable eraser size
    - Only erases pen marks, not content items
    - Clean up mistakes easily

    **[Clear Canvas Button]**

    The "Clear" button removes all pen strokes:
    - Keeps images, videos, and PDFs intact
    - Only clears drawn annotations
    - Quick reset for new activities

    **[Color Palette]**

    The trainer can quickly switch between colors for:
    - Color-coding different concepts
    - Making visual associations
    - Teaching color recognition

    ---

    ### Scene 19: Learner Interaction Tools (30 seconds)

    **[Learner's Whiteboard Access]**

    The learner also has interactive capabilities:

    **[Drag Tool Access]**

    When the trainer grants "Drag" permission:
    - The learner can click and drag items on the whiteboard
    - Move images into buckets
    - Rearrange objects
    - Complete sorting activities

    **[Keyboard Tool]**

    The trainer clicks "Keyboard" to give the learner typing access:
    - A virtual keyboard appears on learner's screen
    - Learner can type responses
    - Type letters, numbers, or words
    - Practice literacy skills

    **[Controlled Access]**

    The trainer controls which tools the learner can use:
    - Click tool buttons to grant/revoke access
    - Green highlight = learner has access
    - Gray = learner cannot use this tool
    - Maintains structured learning environment

    ---

    ### Scene 20: Freeze & Session Management (30 seconds)

    **[Freeze Feature]**

    When the trainer needs to prepare something:
    - Click the "Freeze" 🔒 button
    - Learner's screen shows "Please Wait" overlay
    - Learner cannot interact with the whiteboard
    - Prevents accidental changes

    **[Unfreeze]**

    Click "Unfreeze" 🔓:
    - Learner can interact again
    - Normal session resumes

    **[Save Session Button]**

    Throughout the session, the trainer can click "Save Session" 💾:
    - All content, notes, and interactions are saved
    - Video recording is stored
    - Prompt/reinforcement data is logged
    - Creates permanent record for review

    **[End Session]**

    When the lesson is complete:
    - Click "End Session" ⏹️
    - Confirmation dialog appears
    - All data is finalized
    - Session report is generated
    - Both participants are redirected to their dashboards
