    # HurshBin Tech Platform - Demo Video Script
    ## User Flow: Admin → Head → Trainer → Learner → Session Management

    ---

    ## Introduction (10-15 seconds)

    Welcome to HurshBin Tech - a comprehensive learning management platform designed for intervention programs. Today, we'll walk through the complete user flow, from user creation to conducting live sessions.

    ---

    ## PART 1: User Management Hierarchy (2-3 minutes)

    ### Scene 1: Admin Creates Head (45 seconds)

    **[Screen: Admin Dashboard]**

    Let's start by logging in as an administrator. The admin has full control over the platform and is responsible for creating Head users who will manage their respective teams.

    **[Navigate to: Manage Heads → Register New Head]**

    We click on "Manage Heads" and then "Register New Head." 

    **[Fill out the form]**

    Here we enter the Head's basic information:
    - Name
    - Email address  
    - Contact number
    - Age and address

    **[Scroll to Professional Information]**

    Next, we add professional details:
    - Qualifications
    - Years of experience
    - Date of joining
    - Their experience with HurshBin

    **[Upload Reference Data]**

    We can also upload reference documents - these could be certificates, resumes, or any supporting documents. The system supports PDFs, images, and videos.

    **[Click Register]**

    When we submit, the system generates a unique passcode for the Head user. This passcode is displayed on screen and can be used for login.

    **[Show success message]**

    Notice the success modal showing the generated passcode. This is automatically created by the system to ensure secure access.

    ---

    ### Scene 2: Head Creates Trainer (45 seconds)

    **[Screen: Head Dashboard after login]**

    Now let's log in as the Head we just created, using the passcode that was generated.

    **[Navigate to: Manage Trainers → Register New Trainer]**

    From the Head's dashboard, we navigate to "Manage Trainers" to add a new trainer to the team.

    **[Fill trainer details]**

    Similar to the Head registration, we enter:
    - Basic information
    - Contact details
    - Professional qualifications
    - Experience details

    **[Reference Data Section]**

    Again, we can upload supporting documents for the trainer's profile.

    **[Submit Form]**

    Upon submission, a unique passcode is generated for the trainer.

    **[Show passcode in success modal]**

    The system displays the passcode which the trainer will use to access their account.

    ---

    ### Scene 3: Head Creates Learner (45 seconds)

    **[Navigate to: Manage Learners → Register New Learner]**

    Now let's add a learner to the program. We click on "Manage Learners" and select "Register New Learner."

    **[Fill learner details]**

    For learners, we capture:
    - Personal information
    - Guardian details
    - Contact information
    - Program-specific details

    **[Personal Details Section]**

    Notice we can add comprehensive information including:
    - Self-description
    - Interests
    - Future vision
    - Guardian descriptions

    **[Reference Data Upload]**

    We can upload assessment reports, medical documents, or other relevant files.

    **[Submit and show passcode]**

    Once registered, the learner receives their unique passcode for platform access.

    ---

    ## PART 2: Content & Goals Management (1.5-2 minutes)

    ### Scene 4: Admin Adds Learning Content (45 seconds)

    **[Screen: Admin Dashboard → Manage Learning Content]**

    Now let's switch back to the admin account to add learning resources to the platform.

    **[Click "Add New Content"]**

    We click the "Add New Content" button to upload learning materials.

    **[Upload File]**

    The system supports various file types:
    - Videos for visual learning
    - PDFs for documents
    - Images for reference materials
    - Audio files

    **[Fill content details]**

    We add a descriptive title and description to help users understand what this content is about.

    **[Show upload progress]**

    Notice the upload progress indicator - the system handles files up to 100MB in size.

    **[Submit and show content card]**

    Once uploaded, the content appears in a visual card format, showing:
    - Content type icon
    - File size
    - Upload date
    - Preview thumbnail

    ---

    ### Scene 5: Admin Creates Learning Goals (45 seconds)

    **[Navigate to: Manage Learning Goals]**

    Next, we set up learning goals that will guide the intervention programs.

    **[Click "Add New Goal"]**

    We click "Add New Goal" to create a new learning objective.

    **[Fill goal details]**

    Here we define:
    - Goal title
    - Detailed description
    - Associated program type (if applicable)
    - Success criteria

    **[Attach learning content]**

    We can link the learning content we just uploaded to specific goals, creating a structured learning path.

    **[Show goal in list]**

    The created goal now appears in the goals list, ready to be assigned to sessions.

    ---

    ## PART 3: Session Management & Execution (2-3 minutes)

    ### Scene 6: Head Creates Session (1 minute)

    **[Screen: Head Dashboard → Manage Sessions]**

    Back in the Head's account, let's create a learning session.

    **[Click "Create New Session"]**

    We navigate to "Manage Sessions" and click "Create New Session."

    **[Select Trainer & Learner]**

    First, we select:
    - The assigned trainer from our team
    - The learner who will participate
    - The coach who will support the session

    **[Choose Date & Time]**

    We schedule the session by selecting:
    - Preferred date
    - Start time
    - Duration

    **[Select Learning Goals]**

    Now we attach learning goals to this session. These goals will guide what the trainer and learner work on.

    **[Add Program Details]**

    We can specify:
    - Program type (IIP or Home-based)
    - Session objectives
    - Any special notes

    **[Submit Session]**

    When we create the session, all participants - trainer, learner, and coach - are notified.

    **[Show session in calendar view]**

    The session now appears in the sessions list with status "Scheduled."

    ---

    ### Scene 7: Trainer Starts Session (45 seconds)

    **[Screen: Trainer Dashboard at session time]**

    At the scheduled time, the trainer logs into their account.

    **[Navigate to: My Sessions → Today's Sessions]**

    The trainer can see their scheduled session for today.

    **[Click "Start Session"]**

    When ready, the trainer clicks the "Start Session" button.

    **[Show session interface]**

    The session interface opens with:
    - Video conferencing area
    - Learning goals sidebar
    - Interactive whiteboard
    - Session notes section
    - Learning content access

    **[Demonstrate features briefly]**

    The trainer can:
    - Share their screen
    - Use the whiteboard for interactive teaching
    - Access uploaded learning materials
    - Track progress against goals

    ---

    ### Scene 8: Learner Joins Session (30 seconds)

    **[Screen: Learner Dashboard]**

    Meanwhile, the learner logs into their account using their passcode.

    **[Show notification/session alert]**

    The learner sees a notification that their session is active.

    **[Click "Join Session"]**

    They click "Join Session" to enter the virtual classroom.

    **[Show learner's session view]**

    The learner's interface shows:
    - Video feeds of trainer and themselves
    - Shared learning materials
    - Interactive whiteboard
    - Chat or reaction features

    **[Show both screens side by side]**

    Now both trainer and learner are connected and can interact in real-time.

    ---

    ### Scene 9: Session in Progress (30 seconds)

    **[Show active session with both participants]**

    The session is now live with both participants engaged.

    **[Demonstrate real-time features]**

    Notice the real-time collaboration features:
    - Live video and audio communication
    - Shared whiteboard for visual learning
    - Access to learning content and goals
    - Progress tracking throughout the session

    **[Show session notes being taken]**

    The trainer can take notes during the session, documenting progress and observations.

    **[Show learning goals being checked off]**

    As goals are achieved, the trainer can mark them as completed, providing instant feedback.

    ---
